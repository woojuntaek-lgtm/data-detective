# 데이터 탐정

숫자가 같아도 그림은 다르다 — 평균의 함정(동네 연봉), 앤스콤의 네 묶음(1973), 잔차 보기, 튀는 값과 빈칸(센서 온도와 판다스 info·describe), 로그 눈금 재표현을 손으로 체험하며 배우는 탐색적 데이터 분석(EDA) 첫걸음 앱입니다. 빅데이터 01 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 평균 함정: 열 명 동네 연봉(부자 연봉 슬라이더, 고르게 모인 동네 비교) — 평균 vs 중앙값, 저항성 + 퀴즈
- ② 네 얼굴: 앤스콤 네 묶음의 요약 숫자(실제 점으로 계산) → 예측 퀴즈 → 산점도·직선, 잔차 보기, 튀는 점 빼고 다시 계산
- ③ 탐정 도구: 센서 온도 8개(설명용 예시)의 df.info()/df.describe() 출력, "지울까? 물을까?", 로그 눈금 재표현(예시 데이터)
- ④ 한눈에: 분석 여정 6단계, 탐정과 판사, 튜키의 네 원칙, 처음 받았을 때 5단계 체크리스트, 세 줄 정리, 생각해 볼 질문
